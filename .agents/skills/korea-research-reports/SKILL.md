# korea-research-reports

한경 컨센서스를 한국 증권사 리포트의 발견·원문 확인 경로로 사용한다. 목록 메타데이터와 PDF 내용을 구분하고, 리포트의 전망을 회사의 확정 사실이나 시장 전체 컨센서스로 표현하지 않는다.

## 조사 경로

기본 조회 범위는 최근 30일, 최대 3페이지다. 사용자가 기간을 지정하면 그 범위만 사용한다. 종목코드를 알면 이름보다 종목코드 필터를 우선한다.

```bash
uv run .agents/skills/korea-research-reports/scripts/list_hankyung_reports.py \
  --ticker 005930 --pages 3
```

목록 결과의 `report_idx`를 source key로 사용한다. 같은 `report_idx`를 중복 처리하지 않는다. 제목이 같아도 `report_idx`가 다르면 별도 게시물일 수 있으므로 자동 병합하지 않는다.

PDF 본문이 질문에 필요할 때만 최신성·증권사·제목을 보고 관련 리포트를 고른다. 한 번의 좁은 질문에 기본 3개를 넘겨 내려받지 않는다.

```bash
uv run .agents/skills/korea-research-reports/scripts/render_hankyung_report.py \
  --report-idx REPORT_IDX --output /tmp/hankyung-REPORT_IDX.md
```

변환된 Markdown에서 질문에 필요한 부분만 읽는다. 표 추출이 깨지거나 텍스트가 비어 있으면 PDF를 직접 확인하거나 다른 원문을 찾고, 추정으로 복원하지 않는다.

## 증거와 해석

- 게시일·제목·적정가격·투자의견·작성자·증권사와 원본 URL은 해당 페이지 기준 `FACT`다.
- 리포트 안의 실적 전망·목표주가·산업 전망은 해당 증권사의 `ESTIMATE` 또는 reported opinion이다.
- 여러 리포트의 평균을 계산할 때 동일 대상 기간·회계기준·통화인지 확인하고 기관 수와 기준일을 밝힌다. 리포트 검색 결과 전체를 검증하지 않았다면 "시장 컨센서스"라고 부르지 않는다.
- Codex가 리포트를 비교해 도출한 변화나 thesis 영향은 `LLM_INFERENCE`다. 중요한 결론에는 반대 견해 또는 확인하지 못한 축을 함께 둔다.
- 목표주가·투자의견만으로 BUY/SELL을 만들지 않는다. 행동 판단을 요청하면 `investment-analysis`의 품질 게이트와 valuation 근거를 함께 적용한다.

## 저작권과 보관

목록은 저빈도로 조회하고 PDF를 일괄 수집하지 않는다. 기본 산출물은 메타데이터, 원본 링크, 필요한 범위의 요약이다. PDF와 변환 전문은 임시 파일로 다루며 사용자가 명시적으로 보관을 요청하지 않으면 영구 저장하지 않는다. 원문 전문이나 긴 발췌를 답변·DB·외부 서비스에 재배포하지 않는다.

## 답변

가장 관련 있는 리포트부터 게시일, 증권사, 작성자, 투자의견, 목표주가와 원본 PDF 링크를 제시한다. 본문을 확인했으면 핵심 주장, 근거가 된 추정치, 이전 전망 대비 변화, 주요 반대 근거를 짧게 요약한다. PDF를 열지 않았으면 메타데이터만 확인했다고 명시한다.
